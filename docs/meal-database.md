## データ構造

### Meal

```rust
pub struct Meal {
    pub id: String,               // 一意なID（例: "breakfast_001"）
    pub name: String,             // 料理名
    pub ingredients: Vec<String>, // 食材リスト
    pub nutrition: Nutrition,     // 栄養情報
    pub meal_type: MealType,      // 食事タイプ
    pub tags: Vec<String>,        // タグ
    pub prep_time: u32,           // 調理時間（分）
}
```

### Nutrition

```rust
pub struct Nutrition {
    pub calories: f32,      // カロリー (kcal)
    pub protein: f32,       // タンパク質 (g)
    pub fat: f32,           // 脂質 (g)
    pub carbohydrates: f32, // 炭水化物 (g)
}
```

### MealType

| 値 | 説明 | 件数 |
|---|---|---|
| `Breakfast` | 朝食 | 6件 |
| `Lunch` | 昼食 | 7件 |
| `Dinner` | 夕食 | 7件 |
| `Snack` | 間食 | 4件 |

## レシピデータ

レシピ（調理手順）が用意されているメニューは以下の5件です。

| ID | 料理名 |
|---|---|
| breakfast_004 | プロテインパンケーキ |
| lunch_001 | 鶏胸肉のグリル定食 |
| lunch_003 | 豚ヒレ肉の生姜焼き定食 |
| dinner_001 | サーモンのムニエル |
| dinner_002 | 鶏もも肉の照り焼き |

`--recipe` オプション指定時、該当するメニューの手順が表示されます。未定義のIDは `None` を返します。

## APIリファレンス

`MealDatabase` が提供するメソッド一覧:

| メソッド | 引数 | 戻り値 | 説明 |
|---|---|---|---|
| `new_embedded()` | なし | `Result<Self>` | 組み込みデータでDB初期化 |
| `filter_by_type(meal_type)` | `MealType` | `Vec<&Meal>` | 食事タイプでフィルタ |
| `get_recipe(meal_id)` | `&str` | `Option<&Recipe>` | レシピを取得 |
| `get_all_meals()` | なし | `&[Meal]` | 全メニュー取得 |
| `count()` | なし | `usize` | 総メニュー数 |
| `count_by_type(meal_type)` | `MealType` | `usize` | タイプ別メニュー数 |
